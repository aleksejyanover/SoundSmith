# 🎹 SoundSmith — кузница твоих песен

Бесплатный музыкальный конструктор прямо в браузере: придумывай мелодии, собирай биты и складывай их в полноценные песни. Без регистрации и установки.

🔗 **Попробовать:** https://aleksejyanover.github.io/SoundSmith/

## Что умеет

- 🤖 **Talking — ИИ-музыкант**: напиши или скажи голосом (🎙) «сделай лоу-фай припев», «поп-песня в тональности соль», «эдэм бит» — и ИИ соберёт музыку за тебя
- 🪙 **Talking (валюта)**: 60 на старт, +25 ежедневный бонус, тратится на ИИ-генерацию (песня — 20, секция — 10, мелодия — 8, бит — 5), экспорт WAV даёт +5
- 👤 **Аккаунты**: заходи под разными никами — у каждого свои Talking и своя песня (хранятся локально в браузере)
- 🎹 **Пианино / синтезатор** — играй мышкой или клавишами (`A S D F...`), 4 тимбра: пила, квадрат, треугольник, синус, с эхом
- 🎼 **Конструктор мелодий** — рисуй ноты на сетке 16 × 15 (такт × ноты)
- 🥁 **Драм-машина** — бочка, малый барабан, хэт и хлопок на 16 шагов
- 🎵 **Структура песни** — секции (интро, куплет, припев…), порядок и повторы
- 🎚 **Микшер** — громкость каждой дорожки, эхо, общий уровень, темп 60–200 BPM
- ⬇️ **Экспорт в WAV** — скачивай свою песню файлом
- 💾 **Автосохранение** в браузере (localStorage)

## Как пользоваться

1. Открой сайт, нажми **▶ Играть** — зазвучит пример из трёх секций.
2. Зайди в **👤 Аккаунт** — создай ник, получи 60 Talking.
3. В **🤖 Talking** попроси ИИ: «сделай целую песню в стиле поп» — или играй руками на вкладках **Мелодия** и **Барабаны**.
4. На вкладке **Песня** меняй порядок секций и микшер.
5. Нажми **Скачать WAV** — и твоя песня у тебя в файле (+5 Talking).

## Технологии

Чистый HTML + CSS + JavaScript и **Web Audio API** — без фреймворков и сборки.
Работает даже с офлайн-рендером через `OfflineAudioContext`.

## Локальный запуск

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```
